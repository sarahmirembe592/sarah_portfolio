Equity Bank Merchant Management Portal

The Equity Bank Merchant Management Portal is a secure web-based platform that supports merchant self-onboarding and admin-assisted onboarding. Self-onboarded merchants submit applications for bank approval before gaining access, and approved merchants can create multiple sub-accounts. The portal enables merchants to view transactions, report and track issues, and export reports, while Equity Bank administrators manage onboarding, support merchants, resolve issues, and escalate them to relevant teams.

↳

Contributed to backend APIs, transaction reporting, authentication and access control, data validation, and application security.

  • Python
  • Django
  • PostgreSQL

Nyondo Stock Management System

Nyondo General Hardware Stock Management System is a web-based inventory management application that supports stock management and related day-to-day business operations. It allows staff to track stock levels, record sales, manage customer information, and monitor inventory through a simple dashboard. The system was built using Python and Django to improve record-keeping, reduce manual work, and make stock management easier.

↳

Worked on an application that brings stock records and essential operations into one place.

  • Python
  • Django
  • SQLite

Open Data Ensemble

Open Data Ensemble (ODE) is an open-source platform that supports offline mobile data collection and synchronisation, allowing users to collect and manage data even without an internet connection. I contributed to the project by fixing a Rust issue in the observation query compiler to ensure that the . includeDeleted option is respected when compiling queries.

↳

Focused on query behavior for deleted records in an open-source, offline-first data platform.

  • SQLite
